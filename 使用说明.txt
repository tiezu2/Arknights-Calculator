明 日 方 舟 · 练 度 计 算 器  V1.1.0
======================================

【运行】
  双击  启动.bat   或   明日方舟练度计算器V1.1.0.exe

【目录】
  明日方舟练度计算器V1.1.0.exe   主程序（免安装，Windows 10/11 64 位）
  arknights.db                数据库（含你的库存；删除会自动重建空库）
  启动.bat                    一键启动
  app\                        源码
    app_desktop.py            界面（PySide6 自绘，明日方舟风格）
    calc.py                   计算核心（移植自 cn.ark-nights.com V2.23.20）
    importer.py               导入解析（penguin 仓库 / MAA 练度）
    smart_import.py           智能导入（自动识别多种格式）
    import_dialog.py          导入对话框
    skland.py / skland_dialog.py   森空岛扫码登录 + 练度同步
    build_db.py               data\*.json -> arknights.db
    icons\materials\          98 张材料图标
    icons\operators\          469 张干员头像
  data\                       干员/材料/等级表/物品映射 JSON
  docs\                       界面截图
  _src\                       站点原始 bundle 与逆向模块

【使用】
  1. 左侧搜干员（支持拼音）；职业分组可点标题折叠（＋ 收起 / － 展开）
  2. 目标项三页勾选（等级·阶段 / 技能 / 模组），各自填 现 → 目标
  3. 点「加入计算表」，右侧为该干员自动建标签页
  4. 「库存」页填材料数量，材料合计/缺少 实时计算（含可合成提示）
  5. 顶栏「导入」：森空岛（扫码登录+同步练度）/ 智能导入（全部）/ 库存 / 干员列表
